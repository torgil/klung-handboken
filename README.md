# klung-handboken

Generic klung-handbook — how klungor work, how to ride in a group,
how to handle common situations. Race-agnostic and club-agnostic
(reused across NocOut/CK Hymer/other clubs and across races).

## Layout

- `klung_handboken.md` — the handbook source.
- `images/` — diagrams (SVG), photos, hand-signal illustrations.
- `scripts/` — SVG renderer for the formation diagrams.

## Render

The handbook will eventually be rendered on a separate site.
Until then, read the `.md` directly.

## Race-specific docs go elsewhere

Race-specific requirements documents live in the corresponding
race repos, not here. The handbook stays generic.
